# Publishing checklist

This folder is designed to be the **only** thing you upload. Do not initialize
a repository in the parent folder: it contains the game and localization
files.

## 1. Pre-flight

Run from this folder:

```bash
python -m unittest discover -s tests -v
python tools/check_repo.py
```

The guard fails on media/game/binary extensions, files over 2 MB, absolute
home paths, and hash-like strings. Review any warning manually; do not weaken
the guard just to make it pass.

Then inspect what Git would publish:

```bash
git status --short
git diff --stat
```

Only `.py`, `.md`, `.json`, `.toml`, `.yml`, `LICENSE`, `.gitignore`, and the
empty `vnremaster/py.typed` marker should appear. There should be no `.pac`,
image, font, executable, archive, or backup file.

## 2. Create the repository

```bash
cd galgame-remaster-kit
git init
git add .
git status                 # read this before committing
git commit -m "Initial commit: galgame-remaster-kit"
```

Create an empty public repository on GitHub, then:

```bash
git branch -M main
git remote add origin <your-repository-url>
git push -u origin main
```

Alternatively use the GitHub CLI:

```bash
gh repo create galgame-remaster-kit --public --source=. --remote=origin --push
```

## 3. Suggested repository metadata

Description:

> Galgame remaster toolkit: archive repacking, CJK glyph coverage, and
> display-pipeline A/B measurement. No game assets included.

Topics:

```text
visual-novel  reverse-engineering  deflate  cjk  font-coverage
image-quality  preservation  python
```

## 4. What to say in a portfolio/README

Lead with the engineering, not the game:

- parsed an undocumented sequential-zlib archive and built a rebuild path
  that preserves exact compressed sizes and untouched bytes;
- implemented a dependency-free TrueType/OpenType `cmap` reader and a
  reversible CJK glyph-substitution audit;
- designed an A/B methodology that compares the final panel output instead of
  an intermediate framebuffer;
- shipped deterministic synthetic fixtures and a cross-platform test suite;
- kept the repository clean of copyrighted assets by design.

## 5. What not to do

- Do not upload the game folder, extracted assets, translation tables,
  screenshots, patched executables, or save files.
- Do not name the game or publisher in the public repository if your goal is a
  generic portfolio piece. Describe the engine class and the constraints
  instead.
- Do not add a screenshot just because it looks impressive. A single
  copyrighted frame can change the risk profile of the whole repository.
- Do not publish a game-specific codebook or archive offsets. Publish the
  method and let others build their own tables.

## 6. If you later add synthetic screenshots

The current `.gitignore` and `tools/check_repo.py` block images by default.
If you intentionally add a **synthetic** screenshot (generated by
`vnremaster.demo`), review it, update the allowlist, and keep the original
scene deterministic. Never add a capture of a commercial game.
