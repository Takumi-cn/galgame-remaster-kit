# Notice and scope

This repository contains **code and documentation only**. It deliberately
does **not** include:

- game executables, archives, images, audio, scripts, or fonts;
- extracted or translated game text;
- patched/redistributed game builds;
- keys, decryption material, or DRM-circumvention code;
- screenshots from any commercial game.

The tools are generic utilities for interoperability, preservation research,
and education. They are not affiliated with or endorsed by any game
developer or publisher. Names and trademarks belong to their respective
owners.

If you use these tools with a game, you are responsible for making sure your
use complies with the applicable license and law. Do not use this project to
distribute copyrighted content.

The demo fixtures are generated from code in `vnremaster/demo.py`. The glyph
map in `examples/demo_map.json` is a small illustrative subset of common
Simplified-to-Japanese glyph substitutions, not a copy of any product's
translation data.
